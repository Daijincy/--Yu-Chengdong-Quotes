- ✅ 原话可查：有媒体报道、发布会录像或官方资料可以对应。
- 🟡 媒体转述：媒体明确报道为余承东观点，但原始完整视频/文字稿暂未核验。
- ⚠️ 网络流传：来自网友整理、二次传播或视频剪辑，暂不能确认完整语境。
- 💡 梗/二创：已经成为网络流行表达，但不应当作余承东逐字原话。

🧾 可信度说明

本项目不希望成为简单的"余承东语录梗图合集"。

对于以下内容：

«"麦弗逊根本比不了双叉臂"
"麦弗逊比双叉臂操控更好"
"HUD比仪表盘还清晰"
"HUD根本比不上仪表盘"
"我们一年搞出三辆来"
"我们不造整车"
"售价低于30万的高阶智驾都是亏本销售"
"华为折叠屏卖16999元还是亏本"»

网络上存在大量所谓"余承东名言大全"，但其中部分来自网友汇总，甚至可能将不同年份、不同场合、不同语境的讲话拼接在一起。

因此：

没有找到可靠原始出处 ≠ 余承东一定没说过。

本项目只是在当前资料范围内标记其可验证程度。

第十板块「网络梗 / 二创名场面」中的内容均为经过网友二次创作的迷因，不应视为余承东逐字原话，但它们是"余式文化"的重要组成部分，故单独收录。

- 输入关键词一键生成"XX，业界第一，没有之一"风格文案
- 支持复制、TTS 朗读、再来一条
- 生成历史记录（最多 20 条）

**新页面：发布会音效板（soundboard.html）**
- 40 个经典台词按钮，分 4 大类（经典名场面/汽车问界/鸿蒙技术/梗二创）
- Web Speech API 语音合成朗读，支持中文
- 语速（0.5x-1.5x）和音调（0.5x-1.5x）实时调节
- 底部"正在播放"动态提示条，一键停止

**车型页（cars.html）**
- 17 款搭载华为鸿蒙智慧座舱的车型，base64 内嵌图片
- 按品牌/年份两种分类方式切换
- 点击卡片跳转懂车帝对应车型搜索页
- 图片自带懒加载（loading="lazy"）
