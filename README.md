🧾 可信度说明

本项目不希望成为简单的“余承东语录梗图合集”。

对于以下内容：

«“麦弗逊根本比不了双叉臂”
“麦弗逊比双叉臂操控更好”
“HUD比仪表盘还清晰”
“HUD根本比不上仪表盘”
“我们一年搞出三辆来”
“我们不造整车”
“售价低于30万的高阶智驾都是亏本销售”
“华为折叠屏卖16999元还是亏本”»

网络上存在大量所谓“余承东名言大全”，但其中部分来自网友汇总，甚至可能将不同年份、不同场合、不同语境的讲话拼接在一起。

因此：

没有找到可靠原始出处 ≠ 余承东一定没说过。

本项目只是在当前资料范围内标记其可验证程度。
